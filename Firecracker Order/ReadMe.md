## 💰 San Money – Multiple Person Money Management App

San Money is a simple and clean application designed to help users manage and view money-related information in an easy and organized way. The app provides a minimal interface where users can explore financial tools, track useful money resources, and access helpful financial platforms in one place.

The goal of this application is to create a lightweight and easy-to-use environment that connects users to important finance websites such as market information, cryptocurrency tracking, and financial news. With a clean layout and smooth navigation, the app focuses on simplicity and fast access to financial data without unnecessary complexity.

This project was converted into a web version using HTML so it can run directly in a browser while keeping the same simple design and functionality as the original application.
