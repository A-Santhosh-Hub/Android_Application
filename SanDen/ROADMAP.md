# Roadmap

## ✅ Done
- Stage 1 – Private vault (Drop Folder + Private Import), categories, viewers, Liquid Glass UI
- Stage 2 – Phone ↔ PC Continuity Hub: chat, clipboard, file transfer, Python PC companion

## 🔜 Next
- [ ] **PIN pairing + TLS** between phone and PC (security first)
- [ ] Biometric / PIN app lock
- [ ] **Tablet & large-screen layout** (adaptive two-pane UI, `WindowSizeClass`)
- [ ] QR-code connect (scan from PC app)
- [ ] Folder transfer + progress bars in PC app
- [ ] Packaged Windows `.exe` (PyInstaller) and macOS/Linux builds
- [ ] Auto-discovery of the phone (mDNS) in the PC app
- [ ] Foreground service so the hub keeps running with the screen off
- [ ] Screen mirroring (MediaProjection) – experimental

## 💡 Ideas
Share-sheet integration ("Send to PC"), notification mirroring, remote file browsing, multi-device support.
