# Contributing to SanDen

Thanks for helping! 

1. Fork the repo and create a branch: `git checkout -b feature/my-change`
2. Open the project in Android Studio; keep file logic in `data/`, business logic in `domain/`, UI in `ui/`.
3. Run `./gradlew testDebugUnitTest` before opening a pull request.
4. Describe what you changed and how you tested it (phone model / Android version helps).

Good first issues: tablet layout, QR connect, PC app progress bars, translations.
Please report security issues privately via a GitHub security advisory.
